# Visual phishing detection literature

Reviewed 2026-11-24. The prototype uses established visual similarity methods and independently written experiment code. It obtains its own reference inventory and uses one separately licensed general-purpose pretrained checkpoint.

| Approach | Architecture and resources | Limitations for Phase 6A |
| --- | --- | --- |
| Phishpedia, USENIX Security 2021 | Uses Faster R-CNN on screenshots to find identity logos, compares candidates with Siamese ResNetV2-50 features against a reference gallery, and checks the inferred brand against URL ownership. The authors separate screenshot generation from inference. Their study reports about 1.88 seconds on average for the shared screenshot step. [Paper](https://www.usenix.org/system/files/sec21-lin.pdf), [architecture slides](https://www.usenix.org/system/files/sec21_slides_lin-yun.pdf) | Requires a detector, broad reference gallery, and reliable ownership map. Visual similarity can recognize legitimate third-party uses. The repository advertises CC0-1.0. Verify separately supplied weights, data, and mark permissions before reuse. [Repository](https://github.com/lindsey98/Phishpedia) |
| PhishIntention, USENIX Security 2022 | Combines layout detection, OCR-assisted logo matching, credential-taking inference and browser interaction. The paper reports median overhead of 0.69 seconds in its evaluation, versus 0.41 seconds for Phishpedia. [Paper](https://files.usenix.org/s3fs-public/cdn/sec22fall_liu-ruofan.pdf) | The paper studies context beyond logo similarity. Its dynamic interactions and browser capture pipeline are outside the Phase 6A offline scope. The implementation includes a CC0 notice. External corpora, weights and logo rights are separate. [Repository license](https://github.com/lindsey98/PhishIntention/blob/main/LICENSE) |
| VisualPhishNet, ACM CCS 2020 | Learns screenshot similarity with a triplet convolutional network. Positive pairs are linked by website identity and negatives contrast other identities. It depends on representative page captures and feature training, in addition to inference and reference storage. [Paper](https://arxiv.org/abs/1909.00300), [author implementation](https://github.com/S-Abdelnabi/VisualPhishNet) | A screenshot embedding may be sensitive to viewport, language, rendering state and shared templates. This phase has no paired screenshot archive or family-disjoint supervised training corpus. |
| DCT perceptual hash | Represents low-frequency grayscale structure compactly and scores by Hamming distance. The pHash project documents its DCT family and GPLv3 library. Phase 6A implements its own small DCT calculation on OpenCV and excludes the DC coefficient. [pHash design](https://www.phash.org/docs/design.html), [pHash library license](https://www.phash.org/) | Weak spatial tolerance when crop boundaries remove distinctive features, and weak discrimination for marks sharing coarse geometry. |
| ORB, ICCV 2011 | Oriented local keypoints and binary descriptors provide inexpensive Hamming matching. The prototype uses OpenCV's implementation with 256 descriptors and reciprocal ratio matching. [ORB paper](https://mzucker.github.io/swarthmore/papers/rublee2011orb.pdf), [OpenCV ORB documentation](https://docs.opencv.org/4.x/d1/d89/tutorial_py_orb.html), [OpenCV license](https://opencv.org/license/) | Simple marks may have too few keypoints. Similar shapes can share strong local matches. Descriptor storage grows with keypoint and reference counts. |
| MobileNetV3 Small, ICCV 2019 | An efficient mobile architecture found via hardware-aware search. The selected timm ImageNet-1K checkpoint has an Apache-2.0 model card and uses 224 × 224 RGB. The prototype removes the classifier and compares cosine similarity. Only the 10,241,912-byte, revision-pinned safetensors artifact is loaded. [Paper](https://openaccess.thecvf.com/content_ICCV_2019/papers/Howard_Searching_for_MobileNetV3_ICCV_2019_paper.pdf), [pinned model card](https://huggingface.co/timm/mobilenetv3_small_100.lamb_in1k/tree/76b303ec28c466e9df37f4745dfb7aef20ab87ae) | A general ImageNet representation supplies no trained financial-brand decision. Preprocessing choices and visually similar unknowns affect matches, so external calibration is required. Only the weights were used. The ImageNet image dataset and third-party logo galleries were not acquired. |

Published runtime numbers cover different hardware, tasks and camera/browser capture stages. Phase 6A reports measured crop-processing stages, model sizes and CPU commit separately. The study provides no direct performance comparison with screenshot-based systems.
