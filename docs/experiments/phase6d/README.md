## Explicit resize parity

Canvas reads permitted pixels. The browser then applies an explicit widened bilinear filter, using premultiplied alpha and compositing the resized image onto white. This replaces native Canvas resizing in the research harness. On the three frozen synthetic fixtures the minimum embedding cosine was 0.99999428 in two Chromium runs, above the unchanged 0.97 gate. The second run compared nine pair similarities against a predefined absolute error allowance of 0.004. Maximum error was 0.000467 and all three MobileNetV3 recognition decisions agreed at the original score and margin. Cross-origin readback remained unavailable.

Across the two runs, preprocessing plus inference median was 37.40–38.50 ms and p95 was 81.56–132.06 ms. Initialization was 1,465.60–1,851.70 ms. The maximum guarded process-tree peak was 613,818,368 bytes. Each run had 24 warmed observations and two logical CPUs. The gate cleared on these fixtures. Broader formats, real reference transformations, recognition error rates, independent visual data and production latency remain open.
