# Phase 6D visual research

Status is an initial offline research stage. Visual warnings, blocking, shadow testing and telemetry remain NO-GO. Phase 6B and Phase 6C remain draft dependencies with outstanding acceptance and technical checks.

The bounded locator in `research/phase6d/localize.mjs` identifies candidate image, inline SVG and inline CSS background elements using dimensions, header or navigation placement, and logo-related metadata. It returns references to the caller. An optional local reader extracts pixels only from an already-loaded raster image within a two-million-pixel and 2,048-pixel-per-side budget. It performs no fetch or screenshot collection. Hidden candidates are excluded. Inaccessible cross-origin images, unsupported SVG or background candidates and unreadable images return unavailable. The helper is not connected to the product extension. It reports partial results when the candidate limit is reached and unavailable evidence if the candidate scan budget is exceeded. CSS stylesheets, offscreen elements, browser cross-origin fixtures and automatic recognition remain to be evaluated. Presence of a candidate or logo on an unverified domain does not establish phishing.

Run `node --test research/phase6d/*.test.mjs` for the synthetic unit fixture. Additional page-level localization accuracy, legitimate third-party controls, preprocessing parity, recognition, latency, memory and privacy measurements remain open. The Phase 6A native canvas preprocessing gate remains unresolved. No independent visual dataset has been scored and no new model has been trained.

One synthetic Chromium 159 page produced two header candidates, then three after a delayed labelled image was inserted. An unlabelled product image was excluded. The guarded browser job used two logical CPUs, 3.28 seconds wall time, 3.84 CPU seconds and 365,510,656 bytes peak job commit across Chromium and the driver. This single page does not establish localization accuracy or an operational false-positive rate. Run `research/phase6d/browser.cjs` with the existing Playwright and Chromium environment through `research/phase3d/resource_guard.py` to reproduce it. Fifty-four frozen receipt checks passed, excluding grouped membership recomputation.

Two Node tests cover ranking, budget exhaustion, unreadable images and simulated cross-origin failure. A Chromium rerun passed the same synthetic page after adding the local reader and visibility filter. Actual cross-origin readback and recognition integration still require browser fixtures.
