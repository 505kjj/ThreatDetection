## Acquired URL archive

PhishVN v5 is a CC BY 4.0 Vietnamese URL release. Its publisher inventory returned HTTP 200 and the aggregate download returned HTTP 403. The direct archive route redirected to the publisher's HTTPS storage, which returned HTTP 206 for the complete bounded request. The 6,697,259-byte `PhishVN_v3.1.1_open.zip` matches the Phase 3E and publisher SHA-256 `4c610431fd275d8348695653eeacdece861dc7dc65ab09a2068d519247988968`. It is staged privately. No entries or labels were opened. The dataset concerns Vietnamese sites and does not establish Indian financial efficacy. [Publisher release](https://data.mendeley.com/datasets/b97hxbxtpd/5), [dataset methodology](https://doi.org/10.1016/j.dib.2026.113195).

Independent scoring requires a custodian with a documented access history, a dated label policy and overlap exclusion receipts. Use the existing Phase 3E pinned gold NCSC and trusted-organization source policy as an eligibility starting point. Before labels are joined, exclude canonical URL, alias, domain, family and upstream contributor overlap with all training and development views. Use the project’s original URL preprocessing, freeze model hashes and operating thresholds, and record support and exclusion counts by class and time. Keep the same frozen thresholds throughout one-time evaluation. Treat records lacking a supported campaign-family assignment as unknown. Release aggregates and checksums only. The open archive is suitable for a URL transfer investigation; paired page captures require separate rights and custody. [Phase 3E policy](../../../research/phase3e/protocol.json).

PhiShark still requires manual academic eligibility review and an executed data-use agreement. The PhishTrace study describes independent collection dates but the reviewed paper did not establish a rights-cleared downloadable archive or receipt. LegitPhish is CC BY 4.0 but its listed fields omit row-level observation dates and its benign collection primarily represents Wikipedia and Stack Overflow. The PhishTrap and Zenodo source-quality blockers identified in Phase 5E still apply to the intended custody protocol. [PhiShark access](https://phishark2026dataset.com/#access), [PhishTrace paper](https://users.encs.concordia.ca/home/m/mmannan/publications/PhishTrace-eCrime2026.pdf), [LegitPhish release](https://data.mendeley.com/datasets/hx4m73v2sf/1), [Phase 5E source review](../phase5e/README.md).
